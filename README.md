# Outfit選手権

MUZE TOOL BOX のツール。MAZZELの衣装を、予選は4択・決勝は2択で選んでいくと、好きな衣装TOP5が決まります。

- GitHub Pages 対応の静的サイト（ビルド不要・サーバー不要）
- 結果は1枚の画像（1080×1700）で保存・シェアできます

## 遊び方

| モード | 衣装 | 予選（4択） | 決勝（2択） |
| --- | --- | --- | --- |
| 推しメン | 1人の20衣装 | 5問 → 5衣装 | 5衣装の順位を決める（最大8問） |
| 箱推し | 各メンバー4衣装ずつ、毎回ランダムに32衣装 | 8問 → 8衣装（1問に4人ちがうメンバー） | 8衣装からTOP5（最大17問・多くは12〜15問） |

決勝は二分挿入で並べるので、同じ組み合わせを二度聞くことはありません。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | ページ本体（MUZE TOOL BOX 共通ヘッダー付き） |
| `assets/style.css` | 「作業机」ブランドのスタイル |
| `assets/app.js` | 予選・決勝・結果・画像保存のロジック |
| `photos/<member>/01〜15.jpg` | 最強9マス（アー写編）の写真 |
| `photos/<member>/16〜18.jpg` | 最新アー写（2026.09.18）を3分割したもの |
| `photos/<member>/19〜20.jpg` | パフォ衣装編９マスの4枚目・12枚目 |

## 写真の差し替え

1人あたりの枚数は `assets/app.js` の `SHOTS`（いまは20）です。
推しメンモードの予選は4枚ずつなので、`SHOTS` は4の倍数にしてください。
